# Final Legal Verification — All Subjects Unified Phase

**Date:** 2026-10-06  
**Status:** ACTIVE  
**Scope:** Entire canonical legal-content subject catalog  
**Execution model:** One unified phase; section/topic gates remain mandatory.

## Objective
Complete final authoritative legal verification and publication-readiness work across all subject families in one controlled phase. This supersedes the earlier subject-by-subject scheduling convention without weakening mandatory evidence gates.

## Non-negotiable rule
“Single phase” means a single umbrella execution phase, not permission to mark topics verified from sampling, enhancement-object presence, or automated structural checks.

Every applicable topic must still pass:
`INVENTORY → REPOSITORY MAP → GAP CHECK → ENHANCE → SOURCE VERIFY → CASE VERIFY → LEGAL VALIDATE → CONTENT VALIDATE → INTEGRATE → PRODUCTION CHECK → COMPLETE/LOCKED`

## Subject scope
Current subject-progress inventory records 29 subject families and 3,652 canonical topic records. The generated subject-progress report is tracking substantive coverage and must be refreshed as work advances.

## Execution order inside this unified phase
1. Reconcile the complete canonical inventory.
2. Verify statutory/current-law sources for every applicable topic.
3. Verify every material relied-upon case authority against authoritative judgment evidence.
4. Correct unsupported, outdated, repealed, superseded or contradictory propositions without shortening preserved baseline content.
5. Promote only evidence-backed topics.
6. Run full legal/content validation.
7. Run canonical delivery and application integration validation.
8. Run production-readiness follow-up.
9. Execute the Final Content Quality Pass across the complete catalog.
10. Only after the Final Quality Pass closes, resume fresh judgment acquisition.
11. Keep AI/provider implementation last.

## Explicit sequencing decision
Fresh/new judgment acquisition is **DEFERRED UNTIL AFTER THE FINAL QUALITY PASS**.
Existing judgment verification required to support current topic verification remains in scope. This is distinct from acquiring new judgments.

## Completion rule
No subject may be reported as `COMPLETE_LOCKED` unless every applicable inventory item has complete evidence through all applicable gates.

No topic may be promoted merely because an enhancement object exists, a URL exists, a secondary corpus matches a case, another topic in the subject is complete, or automated schema validation passes.

Every completed verification unit must record the exact topic/path, authoritative source, provisions checked, current-law/amendment status, case-law evidence where applicable, verification date, validator/integration evidence, and commit.

## Definition of done
The unified phase closes only when the full catalog has been reconciled and every remaining review/in-progress record is either evidence-backed and promoted, or explicitly accounted for with a documented reason it remains unpublished/in-progress.
