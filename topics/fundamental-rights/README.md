# Fundamental Rights (India) — Part III subject set

Canonical subject working set for Fundamental Rights (Constitution Part III).

## Design

- **Reuses** existing `topic:india:constitution-art-*` / `provision:india:constitution-art-*` entities (Arts 12–35, 21A, 31A–C, 300A). Do not duplicate those IDs.
- **Adds** subject-facing thematic topics under `topics/fundamental-rights/` with IDs `topic:india:fundamental-rights-*`.
- Distinguishes **historical** Article 31 (FR to property repealed) from **current** Article 300A.
