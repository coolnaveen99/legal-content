# Manifests

Publication and discovery manifests for canonical legal content.

## Files

| File | Purpose |
|------|---------|
| `content-manifest.json` | Production discovery index (`manifestVersion` v1) |

## Rules

See [docs/MANIFEST-AND-VERSIONING.md](../docs/MANIFEST-AND-VERSIONING.md) for:

- Generation algorithm
- Entity versioning
- SHA-256 content hashes
- Integrity, ID collision, orphan-reference, and missing-source validation
- Publication snapshot strategy (Git SHA + manifest)

## Schema

`schemas/manifest.schema.json`

`repository` must remain `coolnaveen99/legal-content`.
